Token bucket: API burst

Fires 30 account reads at once. A full bucket lets the first burst through, then refills steadily.

Sliding window: transfer velocity

Sends 8 transfers from Checking to Savings. Only 5 are allowed in any rolling 60s window per account.

Leaky bucket: payroll payouts

Submits a payroll batch of 25 payouts in one call. 20 fit in the queue and are dispatched 1/second; the rest overflow.

Idempotency: retried transfer

Sends the same transfer 3 times with one Idempotency-Key. Money moves once; retries are replayed.
